## Ограничения

26 healthy и3 Unknown в проверенных циклах. Debian/Windows/Omarchy worker-команды возвращают plain text вместо требуемого JSON; их payload не исправляли и зелёные статусы не выдумывали. Это29 настроенных проверок, не обязательно29 отдельных машин.43 resource rows Proxmox остаются деталями одного probe. CPU/RAM/Swap отсутствуют там, где исходный collector их не измеряет.

Jev выдаёт типизированную оценку, не доказанную причинную диагностику; назначение категории также может быть неточным. Manual key override не меняет ключ фонового оценивания. Telegram/remediation не включались.

Gateway ограничивает доступ опубликованного пути, но встроенный Rust HTTP server по-прежнему без app auth, с CORS и без общего body deadline. Нельзя публиковать8088 напрямую. Локальные процессы хоста находятся за границей этой модели защиты. При оборванном POST Caddy2.6 закрывает запрос через5s без изменения категории, но может вернуть пустой200 вместо ошибки; UI ожидает JSON и не трактует это как успешное действие. Нет независимого ревью, проверки другого реального Tailnet-пользователя, Firefox/Safari, физических мобильных устройств или screen reader.

Владелец сначала случайно создал такой же маршрут **на Omarchy**, затем правильно на harness-test. Агент не менял Omarchy. Для удаления только случайного маршрута выполнить **на Omarchy**: `sudo tailscale serve --https=8099 off`. Не выполнять это на harness-test, где8099 нужен Sentinel.
